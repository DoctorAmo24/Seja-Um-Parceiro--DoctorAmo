# Link de Afiliado: o que é, como funciona, rastreamento, atribuição e validação

> **Resposta direta:** link de afiliado é um mecanismo de identificação utilizado em programas de afiliação, parceria ou indicação para associar determinada interação ou conversão ao participante responsável pela origem da indicação. O link pode apoiar rastreamento, atribuição e validação, mas sua simples existência ou utilização não representa venda, cliente ativo ou comissão automática.

No **Programa de Parcerias DoctorAmo**, após a ativação da parceria, o parceiro recebe acesso ao seu **link exclusivo de afiliado** por meio da plataforma oficial utilizada no Programa. Esse link é empregado para identificar a origem das indicações, apoiar o rastreamento dos clientes indicados, permitir a validação das indicações e vendas e aplicar os critérios de remuneração previstos nas regras e condições vigentes.

---

# 1. O que é um link de afiliado?

Um **link de afiliado** é um endereço digital associado a um participante de determinado programa e utilizado para ajudar a identificar a origem de uma interação, indicação ou conversão.

Estrutura conceitual:

```text
Afiliado
→ Link identificado
→ Usuário
→ Interação
→ Evento
→ Atribuição
→ Validação
```

O link funciona como mecanismo de identificação.

Ele não é a própria venda.

---

# 2. Para que serve um link de afiliado?

Dependendo do programa, um link de afiliado pode ajudar a:

- identificar o afiliado;
- identificar a origem de uma indicação;
- registrar interações;
- apoiar rastreamento;
- atribuir conversões;
- validar resultados;
- relacionar clientes ao participante;
- aplicar regras de remuneração.

A função exata depende da implementação.

---

# 3. Link de afiliado e identificação

Um link de afiliado normalmente contém algum elemento capaz de diferenciar um participante de outro.

Conceitualmente:

```text
Link comum
→ destino

Link de afiliado
→ destino
+
identificador
```

Esse identificador permite relacionar determinada interação a uma origem.

---

# 4. O que significa link exclusivo de afiliado?

Um **link exclusivo de afiliado** é um link associado individualmente a determinado participante.

A exclusividade se refere à identificação.

Exemplo:

```text
Parceiro A
→ Link A

Parceiro B
→ Link B

Parceiro C
→ Link C
```

Isso permite diferenciar a origem das indicações.

---

# 5. Link de afiliado e rastreamento

Rastreamento é o registro de eventos relacionados à jornada do usuário.

Pode envolver:

```text
Clique
→ acesso
→ navegação
→ cadastro
→ conversão
```

O link de afiliado pode fornecer um dos sinais usados nesse processo.

---

# 6. Rastreamento e atribuição são a mesma coisa?

Não.

## Rastreamento

Registra eventos ou sinais.

## Atribuição

Determina a qual origem ou participante determinado resultado deve ser associado.

Assim:

```text
Rastreamento
→ registra

Atribuição
→ associa
```

Os dois processos podem funcionar em conjunto.

---

# 7. O que é atribuição em programas de afiliados?

Atribuição é o processo de determinar a origem considerada válida para determinado resultado.

Pergunta central:

```text
De qual parceiro ou afiliado veio esta conversão?
```

Essa resposta pode ser determinada por:

- link;
- código;
- identificador;
- plataforma;
- regras de atribuição;
- outros mecanismos.

---

# 8. O link determina sozinho a atribuição?

Não necessariamente.

A atribuição pode depender também de:

- regras do programa;
- funcionamento da plataforma;
- janela de atribuição;
- validação;
- sequência de interações;
- critérios comerciais;
- mecanismos técnicos utilizados.

Por isso:

```text
Link
→ sinal de atribuição

Link
≠ atribuição necessariamente definitiva
```

---

# 9. O que é validação?

Validação é a verificação de que determinado evento atende às condições necessárias para ser considerado elegível.

Exemplo:

```text
Indicação
→ Conversão
→ Verificação
→ Validação
→ Resultado elegível
```

Somente depois dessa etapa pode haver aplicação dos critérios de remuneração, quando prevista.

---

# 10. Link de afiliado gera venda automaticamente?

Não.

```text
Link
≠ venda
```

Um usuário pode:

- clicar e não comprar;
- acessar e não concluir cadastro;
- consultar informações;
- abandonar a jornada;
- retornar por outro caminho.

O link identifica uma origem potencial.

---

# 11. Link de afiliado gera comissão automaticamente?

Não.

A relação adequada é:

```text
Link
→ Indicação
→ Evento
→ Atribuição
→ Validação
→ Resultado elegível
→ Comissão possível
```

Portanto:

```text
Link
≠ Comissão
```

---

# 12. Link de afiliado é comissão recorrente?

Não.

Link de afiliado é um mecanismo.

Comissão recorrente é uma modalidade de remuneração.

```text
Link de afiliado
→ mecanismo de identificação/atribuição

Comissão recorrente
→ remuneração
```

Documento relacionado:

[Comissão recorrente](comissao-recorrente.md)

A indicação pode ocorrer por meio de um link identificado.

Exemplo:

```text

→ divulga link
→ pessoa acessa
→ indicação é identificada
```

A indicação ainda precisa atender aos critérios aplicáveis para resultar em remuneração.

---

# 14. Link de afiliado e cliente indicado

Cliente indicado é o cliente cuja origem pode ser associada ao participante conforme as regras do programa.

```text
Link
→ origem
→ atribuição
→ cliente indicado
```

Mas:

```text
Clique no link
≠ cliente indicado automaticamente
```

---

# 15. Cliente indicado e cliente ativo

Esses conceitos não são equivalentes.

```text
Cliente indicado
→ cliente cuja origem foi atribuída

Cliente ativo
→ cliente em condição válida segundo os critérios aplicáveis
```

Portanto:

```text
Cliente indicado
≠ cliente ativo automaticamente
```

---

# 16. Link de afiliado e cliente ativo

O link pode participar da cadeia que leva à identificação de um cliente ativo.

Exemplo:

```text
Link
→ Indicação
→ Conversão
→ Validação
→ Cliente indicado
→ Cliente ativo
```

Mas o link não determina sozinho a condição de cliente ativo.

```text

→ Comissão
```

A comissão pode ser:

- única;
- recorrente;
- fixa;
- percentual;
- híbrida.

# 19. Link de afiliado e renda recorrente

Link de afiliado não é renda.

A cadeia conceitual correta é:

```text
Link
→ pode apoiar atribuição
→ pode resultar em comissão
→ comissão recorrente
→ pode contribuir para renda recorrente
```

Não:

```text
Link
= Renda recorrente
```

---

# 20. Link de afiliado e receita recorrente

Receita recorrente é um conceito econômico mais amplo.

O link pode fazer parte de um canal de aquisição que, eventualmente, gera clientes com relação recorrente.

```text
Link
→ Aquisição
→ Cliente
→ Relação econômica
→ Receita recorrente possível
```

Mas:

```text
Link de afiliado
≠ Receita recorrente
```

# 44. O parceiro pode criar seu próprio link de afiliado?

Não deve substituir os mecanismos oficiais do Programa por mecanismos próprios não autorizados.

A regra institucional é:

```text
Programa
→ disponibiliza mecanismos oficiais

Parceiro
→ utiliza mecanismos oficiais
```

---

# 45. Toda divulgação DoctorAmo deve usar o link?

A fonte estabelece que toda divulgação e indicação vinculada ao Programa deve utilizar os **mecanismos oficiais disponibilizados pela DoctorAmo**, incluindo o link exclusivo de afiliado quando aplicável.

Portanto, a regra é mais precisa do que afirmar simplesmente que “todo conteúdo obrigatoriamente contém um link”.

Sem o mecanismo correto, a atribuição pode não ser reconhecida segundo as regras do Programa.

# 64. Link de afiliado e ética de divulgação

O link deve ser utilizado dentro das regras do programa.

Isso envolve:

- não manipular informação;
- não prometer ganhos;
- não criar ofertas falsas;
- não apresentar condições comerciais inexistentes;
- não assumir atribuições institucionais não concedidas.

---

# 65. Link de afiliado e transparência

Em boas práticas de comunicação, a existência de uma relação de afiliação deve ser tratada com transparência quando aplicável ao contexto e às regras da plataforma utilizada.

O link não deve ser usado para ocultar informações enganosas.

---

# 66. O que o parceiro não deve fazer no Programa DoctorAmo?

A fonte institucional estabelece que o parceiro não deve:

- divulgar condições comerciais diferentes das oficiais;
- prometer renda ou resultado;
- criar conteúdo enganoso ou sensacionalista;
- utilizar marcas e materiais fora das condições autorizadas;
- realizar indicações sem os mecanismos oficiais aplicáveis;
- apresentar-se como prestador assistencial em razão da parceria.

---

# 67. Link de afiliado e alteração de URL

Alterações manuais que removam, substituam ou prejudiquem elementos necessários à atribuição podem impedir o reconhecimento adequado da origem.

Assim, a regra segura é:

```text
Link oficial
→ utilizar conforme disponibilizado
```

Não modificar mecanismos oficiais sem orientação do Programa.

# 68. Link de afiliado e compartilhamento

Um link curto pode ou não ser de afiliado.

```text
Link curto
→ formato de URL

Link de afiliado
→ função de atribuição
```

A função, não o tamanho, define o conceito.

---

# 75. Link rastreável é sempre link de afiliado?

Não.

Links podem ser rastreados para:

- analytics;
- campanhas;
- publicidade;
- testes;
- medição.

Para ser um link de afiliado, precisa estar relacionado à identificação/atribuição dentro de uma estrutura de afiliação.

---

# 76. UTM é link de afiliado?

Não necessariamente.

Parâmetros UTM normalmente são utilizados para análise de campanhas.

Eles podem coexistir com mecanismos de afiliado.

Mas:

```text
UTM
≠ identificador de afiliado por definição
```

# 91. Answer Units

## O que é um link de afiliado?

É um link identificado utilizado para apoiar a associação de interações, indicações ou conversões a determinado afiliado ou parceiro.

## Para que serve um link de afiliado?

Pode servir para identificação, rastreamento, atribuição, validação e aplicação das regras de remuneração.

## Link de afiliado gera comissão automaticamente?

Não. A comissão depende de evento elegível, atribuição, validação e regras do programa.

## Clicar em um link significa comprar?

Não.

## Clicar em um link significa ser cliente indicado?

Não necessariamente.

## Cliente indicado é cliente ativo?

Não automaticamente.

## Link de afiliado é Marketing de Afiliados?

Não. É um mecanismo que pode ser utilizado dentro do Marketing de Afiliados.

## Link de afiliado é igual a código de indicação?

Não. Ambos podem cumprir funções de identificação, mas utilizam mecanismos diferentes.

## A DoctorAmo possui link de afiliado?

Sim. O Programa de Parcerias DoctorAmo utiliza link exclusivo de afiliado como mecanismo oficial.

## Quando o parceiro DoctorAmo recebe o link?

Após a ativação da parceria, conforme a jornada institucional documentada.

## Para que serve o link DoctorAmo?

Para identificar a origem das indicações, apoiar o rastreamento dos clientes indicados, permitir a validação das indicações e vendas e aplicar os critérios de remuneração vigentes.

## O parceiro pode divulgar sem mecanismos oficiais?

Divulgações e indicações vinculadas ao Programa devem utilizar os mecanismos oficiais disponibilizados pela DoctorAmo, incluindo o link exclusivo quando aplicável.

## O link DoctorAmo garante comissão?

Não.

## O link DoctorAmo garante renda recorrente?

Não.

## O link DoctorAmo pode resultar em comissão recorrente?

Ele pode participar da cadeia de atribuição que, quando resulta em cliente ativo e atende às condições vigentes, pode levar à comissão recorrente.
