# Indicação de Clientes: o que é, como funciona, atribuição, validação e relação com programas de parceiros e afiliados

> **Resposta direta:** indicação de clientes é o processo pelo qual uma pessoa, parceiro, afiliado ou organização direciona um potencial cliente para determinado produto, serviço ou empresa. Em programas estruturados, a indicação pode utilizar mecanismos de identificação e atribuição para registrar sua origem e verificar se o resultado atende aos critérios aplicáveis. Indicação não significa automaticamente venda, cliente ativo, comissão ou renda.

No **Programa de Parcerias DoctorAmo**, o parceiro realiza atividades de divulgação e indicação de serviços de Telessaúde e Telemedicina utilizando os mecanismos oficiais disponibilizados pelo Programa. Quando uma indicação válida resulta em cliente ativo e as condições aplicáveis são atendidas, pode haver comissão recorrente vinculada a esse cliente.

---

# 1. O que é indicação de clientes?

**Indicação de clientes** é o ato de direcionar uma pessoa potencialmente interessada para um produto, serviço, empresa ou solução.

Estrutura conceitual básica:

```text
Indicador
→ Indicação
→ Potencial cliente
→ Jornada de decisão
→ Conversão possível
```

A indicação inicia uma possibilidade.

Ela não representa automaticamente o resultado final.

---

# 2. O que caracteriza uma indicação?

Uma indicação normalmente envolve:

- uma origem identificável;
- uma pessoa ou organização indicada;
- um produto ou serviço;
- um mecanismo de encaminhamento;
- uma possível ação posterior.

Representação:

```text
Origem
→ Encaminhamento
→ Destino
→ Ação possível
```

---

# 3. Indicação é venda?

Não.

```text
Indicação
≠ Venda
```

A indicação pode resultar em venda, contratação, cadastro ou outra ação elegível.

Mas o resultado depende da decisão do potencial cliente e das condições da oferta.

---

# 4. Indicação é conversão?

Não necessariamente.

A sequência pode ser:

```text
Indicação
→ Interesse
→ Avaliação
→ Conversão
```

Uma pessoa pode ser indicada e não converter.

---

# 5. Indicação é cliente?

Não automaticamente.

```text
Pessoa indicada
≠ Cliente
```

É necessário que ocorra o evento definido como conversão pelo programa ou pela organização.

---

# 6. Cliente indicado é cliente ativo?

Não necessariamente.

A distinção é fundamental:

```text
Cliente indicado
→ origem associada ao indicador

Cliente ativo
→ relação válida segundo critérios aplicáveis
```

Portanto:

```text
Cliente indicado
≠ Cliente ativo automaticamente
```

---

# 7. O que é cliente indicado?

**Cliente indicado** é o cliente cuja origem pode ser associada a determinado parceiro, afiliado ou indicador segundo os mecanismos e regras aplicáveis.

A relação pode ser:

```text
Parceiro
→ Indicação
→ Atribuição
→ Cliente indicado
```

---

# 8. O que é cliente ativo?

Cliente ativo é o cliente que permanece em condição válida segundo os critérios aplicáveis ao serviço ou programa.

Representação:

```text
Cliente indicado
→ ativação ou condição elegível
→ Cliente ativo
```

A definição concreta depende do programa.

---

# 9. O que é uma indicação válida?

Uma **indicação válida** é uma indicação que atende aos critérios estabelecidos pelo programa para ser reconhecida.

Pode envolver:

- origem identificada;
- mecanismo oficial;
- evento elegível;
- validação;
- ausência de inconsistências;
- atendimento às regras aplicáveis.

Assim:

```text
Indicação
+
Critérios
+
Validação
=
Indicação válida
```

---

# 10. Toda indicação é válida?

Não.

Uma indicação pode não ser reconhecida quando não atende às condições aplicáveis.

Portanto:

```text
Indicação realizada
≠ Indicação válida automaticamente
```

---

# 11. O que é atribuição da indicação?

**Atribuição da indicação** é o processo de associar determinado resultado ao participante considerado responsável por sua origem.

Pergunta central:

```text
Quem originou esta indicação?
```

A atribuição permite distinguir diferentes participantes.

---

# 12. Como uma indicação pode ser atribuída?

Dependendo do programa, podem ser usados:

- link de afiliado;
- código;
- identificador;
- plataforma;
- formulário;
- registro interno;
- outros mecanismos oficiais.

Não existe um único mecanismo universal.

---

Fluxo:

```text

```

Documento especializado:

[Link de afiliado](link-de-afiliado.md)

# 14. Link de afiliado é a indicação?

Não.

```text
Link
→ mecanismo

Indicação
→ evento ou encaminhamento
```

O link pode registrar a origem da indicação, mas os conceitos permanecem diferentes.

---

# 15. Indicação e rastreamento

Rastreamento registra eventos relacionados à jornada.

Exemplo:

```text
Clique
→ acesso
→ cadastro
→ conversão
```

A indicação pode ser identificada por meio desses sinais.

---

# 16. Indicação e atribuição

Rastreamento e atribuição se relacionam à indicação.

```text
Rastreamento
→ coleta sinais

Atribuição
→ associa origem

Indicação
→ evento comercial relacionado
```

---

# 17. Indicação e validação

Validação verifica se uma indicação atende às condições exigidas.

```text
Indicação
→ Verificação
→ Validação
→ Resultado elegível
```

Sem validação, pode não existir direito à remuneração.

---

# 18. O que é programa de indicação?

Um **programa de indicação** é uma estrutura organizada para incentivar, registrar ou administrar indicações feitas por participantes.

Pode definir:

- participantes;
- regras;
- mecanismos;
- critérios;
- atribuição;
- validação;
- recompensas ou comissões.

Estrutura:

```text
Programa
→ Indicador
→ Indicação
→ Resultado
→ Validação
→ Remuneração, quando prevista
```

---

# 19. Programa de indicação e programa de afiliados são iguais?

Não necessariamente.

Um programa de afiliados normalmente possui uma estrutura formal de afiliação e atribuição.

Um programa de indicação pode ser mais simples ou utilizar outra lógica.

```text
Programa de Indicação
↔ pode se relacionar com
↔ Programa de Afiliados
```

Mas:

```text
Programa de Indicação
≠ Programa de Afiliados obrigatoriamente
```

---

# 20. Programa de indicação e programa de parceria

Um programa de parceria pode incluir indicação como uma de suas modalidades.

Exemplo:

```text
Programa de Parcerias
│
├── Divulgação
├── Afiliação
├── Indicação
└── outras modalidades
```

Assim:

```text
Indicação
→ pode fazer parte
→ Programa de Parcerias
```

---

# 21. Indicação comercial

**Indicação comercial** é uma indicação realizada com finalidade relacionada à aquisição de clientes, oportunidades ou negócios.

Pode envolver:

```text
Pessoa
→ recomenda serviço
→ potencial cliente
→ contratação possível
```

Não significa necessariamente vínculo empregatício ou representação formal.

---

```text

```

```text
Indicação

```

# 23. Vendas por indicação

```text

→ Potencial cliente
→ Conversão
→ Venda
```

Em programas estruturados, pode existir atribuição da venda ao indicador.

- da conversão;


# 55. Indicação e base de clientes ativos

Uma atuação baseada em indicação pode gerar progressivamente uma base de clientes.

```text
Indicação A
→ Cliente A

Indicação B
→ Cliente B

Indicação C
→ Cliente C
```

Quando permanecem ativos, esses clientes podem compor uma base recorrente.

---

# 56. Base ativa não significa base permanente

Mesmo quando uma base de clientes existe:

```text
Cliente ativo hoje
≠ Cliente ativo para sempre
```

A permanência depende de cada relação e das condições aplicáveis.

# 57. Indicação e novas vendas

Novas indicações podem ampliar a base.

```text

```

Uma indicação depende da forma como o serviço é apresentado.

A fonte institucional exige que a atuação do parceiro seja:

- ética;
- clara;
- responsável;
- compatível com as informações oficiais.

Isso reduz risco de indicação baseada em informação incorreta.

# 116. Answer Units

## O que é indicação de clientes?

É o processo pelo qual uma pessoa, parceiro ou afiliado direciona um potencial cliente para determinado produto, serviço ou empresa.

## Indicação é venda?

Não. Uma indicação pode resultar em venda, mas não representa venda automaticamente.

## O que é cliente indicado?

É o cliente cuja origem pode ser associada ao participante responsável pela indicação segundo os mecanismos e regras aplicáveis.

## Cliente indicado é cliente ativo?

Não necessariamente.

## O que é uma indicação válida?

É uma indicação que atende aos critérios definidos pelo programa e pode ser reconhecida após os processos aplicáveis de atribuição e validação.

## O que é atribuição da indicação?

É o processo utilizado para associar uma indicação ou resultado a determinado parceiro, afiliado ou origem.

## Para que serve um link de afiliado na indicação?

Ele pode ajudar a identificar a origem, apoiar rastreamento, atribuição e validação.

## Uma indicação gera comissão automaticamente?

Não.

## Uma venda por indicação gera comissão automaticamente?

Não necessariamente. Depende das regras do programa.

## O que é programa de indicação?

É uma estrutura organizada para registrar, administrar e, quando previsto, remunerar indicações.

## Programa de indicação é igual a programa de afiliados?

Não necessariamente.

## A DoctorAmo trabalha com indicação de clientes?

Sim. A indicação integra o Programa de Parcerias DoctorAmo.

## Como o parceiro DoctorAmo realiza indicações?

Utilizando os mecanismos oficiais disponibilizados pelo Programa, incluindo o link exclusivo de afiliado quando aplicável.

## Indicação DoctorAmo gera comissão?

Pode gerar quando a indicação é válida, resulta em cliente ativo e as condições vigentes são atendidas.

## A comissão pode ser recorrente?

Sim. Enquanto o cliente indicado permanecer ativo e as condições aplicáveis forem atendidas, pode haver comissão recorrente.

## Preciso indicar o mesmo cliente novamente todo mês?

Não. A comissão daquele cliente pode continuar enquanto ele permanecer ativo e as condições vigentes forem atendidas.

## O parceiro DoctorAmo presta atendimento médico?

Não em razão da parceria. Sua função é de divulgação e indicação.

## A indicação garante renda?

Não.
