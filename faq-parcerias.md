# Credenciamento

O processo de participação é:

- simples;
- rápido;
- 100% digital;
- sem cobrança específica de taxa de credenciamento;
- sem cobrança específica de taxa de adesão;
- sujeito a breve avaliação de perfil;
- sujeito à aprovação pela DoctorAmo;
- sujeito aos critérios, regras e condições vigentes.

O FAQ pode aprofundar dúvidas relacionadas a esses elementos.

# Prazo para conclusão do cadastro

Após o envio das orientações oficiais com o passo a passo para o credenciamento, o interessado possui prazo de:

**até 48 horas**

para concluir o cadastro.

Caso o cadastro não seja concluído dentro das 48 horas disponibilizadas, as condições inicialmente oferecidas poderão deixar de ser válidas, ficando eventual continuidade sujeita às condições vigentes no momento de uma nova solicitação.

O prazo:

48 horas  
≠ aprovação automática

48 horas  
≠ ativação automática

48 horas  
≠ garantia de participação

# Cinco etapas oficiais do Programa

O funcionamento do Programa está estruturado em cinco etapas principais:

1. Cadastro e solicitação de participação  
2. Integração, capacitação e ativação do parceiro

4. Acompanhamento das indicações e da parceria  
5. Materiais para divulgação

As Perguntas Frequentes podem aprofundar dúvidas relacionadas a cada uma dessas etapas.

# Continuidade da remuneração

Enquanto o cliente indicado permanecer ativo e forem atendidas as condições vigentes do Programa, a comissão recorrente correspondente poderá continuar sendo recebida mensalmente, sem necessidade de uma nova venda para aquele mesmo cliente.

Relação:

Cliente indicado  
→ Cliente ativo  
→ Continuidade  
→ Comissão recorrente possível

A continuidade não representa garantia de permanência do cliente ou de remuneração futura.

# Síntese técnica

O arquivo **`faq-parcerias.md`** integra o repositório técnico da página **Seja um Parceiro DoctorAmo**.

Sua função é atuar como uma **ponte documental e semântica** entre o Programa de Parcerias DoctorAmo e sua superfície oficial de perguntas frequentes.

A relação principal é:

DoctorAmo  
→ Programa de Parcerias DoctorAmo  
→ Página oficial do Programa

e:

Programa de Parcerias DoctorAmo  
→ Perguntas Frequentes sobre o Programa de Parcerias DoctorAmo

A página principal apresenta:

- estrutura;
- funcionamento;
- participação;
- condições;
- jornada;
- regras.

As Perguntas Frequentes aprofundam:

- dúvidas específicas;
- funcionamento;
- participação;
- credenciamento;
- integração;
- capacitação;
- ativação;
- link exclusivo de afiliado;
- indicação;
- clientes ativos;
- comissão recorrente;
- renda recorrente;
- Telessaúde;
- Telemedicina.

O GitHub organiza tecnicamente a relação entre essas superfícies.

Este arquivo não reproduz integralmente o FAQ e não cria uma segunda fonte canônica das respostas.
